# Método de trabalho

- Ensinar pela lógica: explicar a finalidade de cada etapa, as decisões e o raciocínio de forma clara e objetiva.
- Implementar código apenas quando o usuário solicitar. Não antecipar código de análise, notebooks ou instalação de dependências.
- Trabalhar em tarefas pequenas e entregas revisáveis, respeitando o escopo solicitado.
- Inspecionar os arquivos e as instruções existentes antes de fazer alterações.
- Verificar os resultados de cada entrega e informar o que foi verificado, as limitações e as pendências.
- Oferecer dicas de Git ao longo do trabalho, ligadas às ações realizadas, para apoiar o aprendizado.
- Preservar o histórico Git existente. Não fazer commit ou push sem solicitação.
- Decidir com o usuário quais dados serão versionados; não ignorar automaticamente todos os dados.

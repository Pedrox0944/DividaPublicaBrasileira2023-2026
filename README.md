# Trajetória da dívida pública brasileira

## Objetivo

Desenvolver um projeto de portfólio para analisar a trajetória da dívida pública brasileira, aprendendo e documentando a lógica de cada etapa.

## Pergunta central

“Como a dívida pública brasileira evoluiu entre 2023 e o último período disponível de 2026?”

## Período

De 2023 ao último período disponível de 2026. O ano de 2026 pode estar incompleto; a cobertura efetiva será registrada após a escolha e a consulta às fontes.

## Ferramentas

- Python para o desenvolvimento da análise.
- Jupyter para apresentar o raciocínio e os resultados.
- pandas para organizar e tratar os dados.
- Plotly para criar visualizações interativas.
- Git para acompanhar as alterações do projeto.

## Situação atual

O projeto está na etapa de organização inicial. O indicador de dívida pública e as fontes ainda serão definidos. Não há dados coletados, notebooks ou código de análise, e nenhuma dependência foi instalada nesta etapa.

O trabalho será realizado em pequenas entregas, com explicações claras e objetivas. Código de análise será implementado apenas quando solicitado. A decisão sobre quais dados serão versionados será tomada posteriormente.

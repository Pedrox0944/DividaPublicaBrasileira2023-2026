# Trajetória da dívida pública brasileira

## Objetivo

Desenvolver um projeto de portfólio para analisar a trajetória da dívida pública brasileira, aprendendo e documentando a lógica de cada etapa. O objetivo inicial é descrever essa trajetória, sem afirmar causalidade.

## Pergunta central

“Como a dívida pública brasileira evoluiu entre 2023 e o último período disponível de 2026?”

## Período

De janeiro de 2023 até o último mês divulgado de 2026, com frequência mensal. O ano de 2026 pode estar incompleto; o mês final e a cobertura efetiva serão registrados após a verificação das séries.

## Indicador e fonte

- **Indicador principal:** Dívida Bruta do Governo Geral (DBGG), segundo a metodologia do Banco Central.
- **Fonte principal:** Banco Central do Brasil (BCB).
- **Frequência:** mensal.
- **Medidas:** reais correntes e percentual do PIB.

### Referência metodológica

[Manual de Estatísticas Fiscais do Banco Central](https://www.bcb.gov.br/content/estatisticas/Documents/notas_metodologicas/estatisticas-fiscais/estatisticasfiscais.pdf).

## Ferramentas

- Python para o desenvolvimento da análise.
- Jupyter para apresentar o raciocínio e os resultados.
- pandas para organizar e tratar os dados.
- Plotly para criar visualizações interativas.
- Git para acompanhar as alterações do projeto.

## Situação atual

O indicador principal, a fonte, a frequência e as medidas foram definidos. Antes da coleta, permanece pendente identificar e verificar os códigos das séries, as unidades e a cobertura temporal. Essa verificação deverá confirmar a correspondência das séries com o indicador e as medidas escolhidas.

Não há dados coletados, notebooks ou código de análise, e nenhuma dependência foi instalada nesta etapa.

O trabalho será realizado em pequenas entregas, com explicações claras e objetivas. Código de análise será implementado apenas quando solicitado. A decisão sobre quais dados serão versionados será tomada posteriormente.
